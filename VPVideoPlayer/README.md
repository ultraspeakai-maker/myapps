# 🎬 VP Video Player - Smart HD Video & Audio Player

**VP Video Player** is a modern, lightweight, high-performance Android video player and media manager inspired by MX Player with a sleek white theme, background playback, folder management, Wi-Fi cross-platform file transfer, audio extractor, and video trimmer.

---

## 📱 Application Overview
- **App Name:** `VP Video Player - HD Media Player`
- **Package Name:** `com.ultraspeakai.vpvideoplayer`
- **Developer Email:** `support@ultraspeakai.com` / `ultraspeakai@gmail.com`
- **Tech Stack:** Kotlin, Jetpack Compose, Material 3, ExoPlayer (Media3), Coroutines, AdMob SDK
- **Architecture:** MVVM, Clean Architecture, Jetpack StateFlow
- **Target SDK:** Android 14 (API 34) / Min SDK: Android 7.0 (API 24)

---

## ⚡ Key Features
- **MX Player White Theme:** Pristine white layout, soft blue card borders, rounded corners, and red notification count badges (`99+`, `97`, `15`) on folder icons.
- **Folder & Video Library View:** Switch seamlessly between folder tree view and flat video list with instant search filtering.
- **Background Video & Audio Playback:** Foreground service allows listening to video audio in the background with lockscreen media controls.
- **Wi-Fi Cross-Platform Share:** Built-in NanoHTTPD web server and QR code generator to transfer videos wirelessly between Android, iPhone, iPad, PC, and Mac.
- **Video Editing Tools:** In-app Lossless Video Trimmer (30s / 60s clips) and MP3 Audio Extractor.
- **Recycle Bin & Safe Recovery:** Local trash bin allowing temporary deletion and 1-tap restoration back to original folder paths.
- **Multi-Language Support (16 Languages):** English, Hindi, Spanish, French, German, Japanese, Korean, Chinese, Arabic, Portuguese, Russian, Italian, Turkish, Indonesian, Vietnamese, Bengali.
- **AdMob Integration:** Google Mobile Ads Banner (`ca-app-pub-5621401237476154/8610569400`) and Exit Interstitial (`ca-app-pub-5621401237476154/8806010526`).
